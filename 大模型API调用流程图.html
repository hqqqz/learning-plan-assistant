大模型 API 调用：从请求到取出答案

以 DeepSeek（OpenAI 兼容接口）为例 · 完整链路 5 步

① 一次调用的完整流程
① 准备连接
client = OpenAI(api_key, base_url)
带着"身份凭证"连接 DeepSeek
→
② 组装消息
messages = [{role, content}]
把"聊天记录"打包好
→
③ 发请求
client.chat.completions.create(model, messages)
真正发网络请求给 DeepSeek
→
④ 收响应
返回 response（一个嵌套 JSON 对象）
AI 的答案藏在这个对象里
→
⑤ 取出答案
response.choices[0].message.content
层层取出正文文字
② 答案藏在哪：一层一层往里取

response 是一个"俄罗斯套娃"，最里面的 content 才是答案。用点号取 key、用 [0] 按下标取。

response · 整个响应对象
先打开最外层
.choices · 候选答案【数组】
是个列表 → 用下标 [0] 取（不是 key）
[0] · 第 0 个候选（index: 0）
默认只生成一个，永远取第 0 个
.message · 消息对象
里面有 role 和 content
.content = ✅ 真正的答案文字
"AI 的回答在这里..."
完整写法： answer = response.choices[0].message.content
⚠️ 流式（stream=True）的区别
你代码里用的是流式：DeepSeek 不返回完整的 response，而是把回答切成一小段一小段返回（每段叫 chunk）， 每段的文字在 chunk.choices[0].delta.content。你需要把每段拼起来才得到完整回答。 st.write_stream() 正是帮你做这个拼接 + 逐字显示。
